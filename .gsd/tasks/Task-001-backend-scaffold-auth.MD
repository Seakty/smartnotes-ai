## Step 8 — services/auth_service.py

Create `AuthService` class with these async methods:

- `register(db, payload: RegisterRequest) -> User`
  - Check email uniqueness → raise 409 if taken
  - Hash password with passlib bcrypt
  - Create and persist User
  - Return User

- `login(db, payload: LoginRequest) -> User`
  - Fetch user by email
  - Verify password with passlib
  - Check is_active
  - Raise 401 "Invalid credentials" for ANY failure
  - Return User

- `create_access_token(user_id: str) -> str`
  - Build payload: `{"sub": user_id, "exp": now + timedelta(minutes=settings.access_token_expire_minutes)}`
  - Sign with `settings.secret_key` and `settings.algorithm`
  - Return token string

- `get_current_user(db, token: str) -> User`
  - Decode JWT with python-jose
  - Fetch user by sub claim
  - Raise 401 if anything fails
  - Return User

## Step 9 — routes/auth.py

Create `APIRouter(prefix="/auth", tags=["auth"])`.

Implement all 4 endpoints from the spec.
Each handler is thin — one line of logic, delegates to `auth_service`.

Cookie settings helper:
```python
def set_auth_cookie(response: Response, token: str):
    response.set_cookie(
        key="access_token",
        value=token,
        httponly=True,
        max_age=settings.access_token_expire_minutes * 60,
        samesite="lax",
        secure=settings.is_production,
    )
```

For `get_current_user` dependency in routes:
```python
async def get_current_user(
    request: Request,
    db: AsyncSession = Depends(get_db),
) -> User:
    token = request.cookies.get("access_token")
    if not token:
        raise HTTPException(status_code=401, detail="Not authenticated")
    return await auth_service.get_current_user(db, token)
```
